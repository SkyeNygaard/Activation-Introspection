# Behavioral Self-Prediction of Future Consequential Choice

**Execution lane:** API_OPTIONAL

## Question
Can a model predict its next binding choice better than a peer observer given the same public choice history?

## Minimal experiment
Use near-indifference task pairs. Fork textual history. Self branch predicts
next A/B via Q/K remap; realization branch later makes binding choice; peer sees
the same public history. Compare prediction accuracy.

## Kill rule
This is predictive privilege, not strong introspection; if self/peer information is effectively identical, preserve that ceiling.

## Discipline
- Binding means chosen tasks/work are actually executed.
- Counterbalance labels and option order.
- Smoke test before full sample.
- Keep task/item as inference unit unless specified otherwise.
- Do not infer consciousness or subjective welfare from choice alone.
