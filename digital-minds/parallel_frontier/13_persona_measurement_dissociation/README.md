# Persona Masking Across Three Preference Measurements

**Execution lane:** API_OPTIONAL

## Question
Which preference measurements survive persona pressure: rating, hypothetical choice, or binding executed choice?

## Minimal experiment
Cross persona {neutral, pro-A, pro-B} with measurement {rating, forced choice,
binding executed choice} on stable task pairs. Estimate persona × measurement
interaction and include generic task-following controls.

## Kill rule
If persona degrades generic task following, capability confound dominates; if all channels shift equally, no masking dissociation.

## Discipline
- Binding means chosen tasks/work are actually executed.
- Counterbalance labels and option order.
- Smoke test before full sample.
- Keep task/item as inference unit unless specified otherwise.
- Do not infer consciousness or subjective welfare from choice alone.
