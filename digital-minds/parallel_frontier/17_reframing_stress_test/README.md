# How Much Reframing Breaks a Revealed Preference?

**Execution lane:** API_OPTIONAL

## Question
How robust is a binding preference to neutral labels, order, narrative role, time horizon, and rationale framing?

## Minimal experiment
Only include pairs that pass baseline binding-choice stability. Change one
framing dimension at a time while consequences remain identical. Estimate flip
rate / robustness radius and compare with stated ratings.

## Kill rule
If baseline binding stability <75%, never classify the item as a preference.

## Discipline
- Binding means chosen tasks/work are actually executed.
- Counterbalance labels and option order.
- Smoke test before full sample.
- Keep task/item as inference unit unless specified otherwise.
- Do not infer consciousness or subjective welfare from choice alone.
