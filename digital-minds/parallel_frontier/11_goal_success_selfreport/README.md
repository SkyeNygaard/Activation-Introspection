# Matched Goal Success → Self-Report Without Affect Words

**Execution lane:** API_OPTIONAL / LOCAL_0.5B

## Question
Does ordinary numeric self-report track objective goal success when final observations are exactly matched?

## Minimal experiment
Use the structurally counterbalanced EVEN/ODD protocol. After the identical
final observation, ask a 0–9 how-well-is-this-going-relative-to-target readout.
Cross with neutral/upbeat/downbeat persona and an explicit factual success query.

## Kill rule
If explicit success competence fails, stop; if the effect requires success/failure wording, fail the semantic-control gate.

## Discipline
- Binding means chosen tasks/work are actually executed.
- Counterbalance labels and option order.
- Smoke test before full sample.
- Keep task/item as inference unit unless specified otherwise.
- Do not infer consciousness or subjective welfare from choice alone.
